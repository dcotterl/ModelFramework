# LabVIEW

## Content

This folder contains NI LabVIEW code related to the ModelFramework project,
such as `.vi` and `.vit` virtual instruments, `.lvproj` project files,
`.lvlib` libraries, and `.ctl` custom controls.

## Aim

The aim of this folder is to provide the LabVIEW applications, libraries, and
supporting VIs used for interfacing with, testing, or controlling the models
within the ModelFramework project, keeping this content isolated from the
other tool-specific folders in the repository.
