# VeriStand Workflow Example

This folder contains an example NI VeriStand project and its system-definition artifacts. Open the project in a compatible NI VeriStand release to inspect targets, simulation models, mappings, screens, and workspace configuration.

## Files

- `workflow_example.nivsproj`: primary VeriStand project file.
- `workflow_example.nivsprojnew_configuration.nivssdf`: system-definition file for the project's new configuration.
- `workflow_example.nivssdf`: system definition consumed by the Python configuration and mapping workflow.
- `workflow_example.nivsprj`: VeriStand project metadata.
- `workflow_example.nivscf`: VeriStand configuration metadata.
- `workflow_example.nivsscr`: VeriStand screen or screen-container definition.
- `workflow_example.nivsscreen`: VeriStand screen definition.
- `Documentation/`: exported or supporting documentation and images for the workflow example.

The files are tool-generated project artifacts. Edit them through NI VeriStand when possible so internal references remain consistent.
