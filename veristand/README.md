# VeriStand

## Content

This folder contains NI VeriStand projects, system definition files, screens,
and configuration used in the ModelFramework project, such as `.nivssdf`
system definition files, `.nivsproj` project files, custom devices, and
screen/UI files.

## Aim

The aim of this folder is to provide the VeriStand configuration and projects
used for real-time testing and simulation of the models within ModelFramework,
keeping this content isolated from the other tool-specific folders.

## Files

- `mapping.txt`: checked-in channel mappings for the example Controller target.
- `generated_mapping.txt`: mapping output generated by Python from Simulink
	Goto/From connections.
- `workflow_example/`: VeriStand project and system-definition artifacts.

The `.gitignore` file excludes VeriStand-generated temporary and user-specific
files that should not be committed.

The Python builder in [`python/utilities/README.md`](../python/utilities/README.md)
creates configurations, discovers compiled `.vsmodel` files, and imports
mapping files into a system definition. VeriStand must be installed and
registered for those operations to work.
