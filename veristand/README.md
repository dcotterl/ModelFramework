# VeriStand

## Content

This folder contains NI VeriStand projects, system definition files, screens,
and configuration used in the ModelFramework project, such as `.nivssdf`
system definition files, `.nivsproj` project files, custom devices, and
screen/UI files.

## Aim

The aim of this folder is to provide the VeriStand configuration and projects
used for real-time testing and simulation of the models within the
ModelFramework project, keeping this content isolated from the other
tool-specific folders in the repository.
